# 账号、用量与配置管理

## 查询顺序

只问余额时使用 `user_balance`，其 `data` 是金额字符串，单位元；需要拆分时使用 `user_info`，区分 `money` 总余额、`origin_money` 充值余额和 `give_money` 赠送余额，不把三者再次相加。

涉及某个代理账号时，先明确产品，再用 `sub_account_list` 定位。优先使用用户给出的账号、IP 或备注进行受支持的筛选；同名或多条匹配时先让用户选定，不自行挑一条执行修改。普通余额和用量报告不需要展示密码。

- 子账号列表从第 1 页开始，每页最多 100 条。查询“全部”时继续分页，直到返回总数已覆盖或没有更多记录；只读取了部分页时，明确报告范围，不能把当前页汇总称为全部。
- 动态不限流量带宽列表仅支持分页。需要按地区、账号或状态筛选时，先按请求范围取页，再筛选返回结果，不添加该产品不支持的查询参数。
- 动态不限流量带宽后续操作使用 `rows[].sub_account`，其他产品通常使用返回的 `id`。按工具说明传字符串，不能把本地记录 `id`、账号名、出口 IP 和子账号标识互相替代。
- 列表为空只表示本次产品与查询条件未返回账号，不等于整个账户没有产品。先检查产品和筛选条件，再决定是否扩大查询。

## 用量、单位与日期

两种动态住宅流量产品分别查询，不能把永久流量与期限流量当成同一个主账号。使用 `main_account_flow` 查看主账号汇总，使用 `flow_package_list` 查看已购套餐记录，使用 `sub_account_flow` 查看指定子账号的每日用量。

| 数据或参数 | 单位与解释 |
| --- | --- |
| `main_account_flow` 的 `use`、`base`、`total` | GB，分别为已用、剩余和总流量；保留接口返回值，不用缺失字段自行补零。 |
| `sub_account_flow` 的 `flow` | MB；不要把每日值直接标成 GB，换算或汇总时说明单位与日期范围。 |
| 流量上限配置中的 `limit_flow`、`use_flow` | GB；前者是上限，后者是该配置记录的已用量，不等于所有历史用量。 |
| 动态不限流量带宽 | Mbps；升级参数表示升级后的总带宽，不是增加量。 |
| `changeInterval` | 分钟；这是动态流量子账号的切换间隔，不是查询时间范围。 |
| `bandwidth_trend` 的 `startTime`、`endTime` | 秒级时间戳，不是毫秒。 |

`sub_account_flow` 使用 `YYYY-MM-DD`，单次区间最多 30 天，结束日期不能晚于当前日期。“最近 7 天”等相对范围先换成明确起止日期，并说明是否包含当天；跨时区需求先确认采用的日期口径。更长区间拆成互不重叠的有效区间，避免重复累计同一天。只有完整返回后才报告区间总量；部分查询失败时保留已查范围并说明缺口。

查询单个供应商用量时，`spec` 为整数编号。`provider_list` 返回字符串数组，且目前固定查询永久流量主账号，不能保证期限流量的资源池范围；详见[地区与资源池查询](products.md#地区与资源池查询)。未指定时查询全部，不将分资源池结果与“全部”结果重复相加。

三种静态住宅 IPv4 产品可查询带宽详情和趋势。历史趋势跨度最多 31 天；`bandwidth_detail` 有 120 秒缓存，不用高频重复查询来判断修改是否已生效。不要把这些工具套用到动态不限流量或数据中心产品。

## 配置修改范围

修改前必须读取[子账号管理](account-lifecycle.md)。动态备注、间隔、限流及动态/时长产品的账密工具会同时发送协议等默认值，不能保证只改指定字段。用户要求其他配置不动且没有接受副作用时，不发起这类写调用。完成后使用对应查询核对；无法复核的字段明确说明。

- 动态流量单个备注使用 `sub_account_update`；批量备注或切换间隔使用 `sub_account_update_batch`。批量工具的 `ids` 使用英文逗号分隔；只传用户明确要修改的字段仍不能消除上述后端副作用。
- 流量上限仅支持两种动态流量产品。先用 `sub_account_limit_flow` 或批量查询读取现有配置；每个子账号只允许一个周期，修改周期不是增加第二条独立限制。`limit_flow=0` 表示删除限制，不表示停用账号或零流量配额；周期为永久时按累计用量处理，不会在下个周期清零。
- 设置自定义账密会覆盖所选账号的用户名和密码，不能作为读取连接配置的前置步骤。`sub_account_set_credentials` 当前不支持动态不限流量带宽。`sub_account_set_password_batch` 仅支持三种静态住宅 IPv4 与数据中心产品，且账号必须已设置自定义账密；不能用它修改系统默认账密，也不能静默改用另一工具同时修改用户名。
- `sub_account_toggle_port` 仅支持三种静态住宅 IPv4 产品，修改的是端口连接状态；关闭可能中断现有连接，不能当作删除账号、申请退款或切换出口 IP。
- 当前 `sub_account_whitelist` 只读取动态流量子账号白名单，没有对应的白名单修改工具。不要根据后端可能存在接口就宣称能修改。

动态不限流量带宽操作前检查 `can_renew`、`can_upgrade`、`refunding` 等返回状态。列表可能在上游不可用时返回本地账密并留空连接信息；不要把查询成功解释为连接可用，也不要编造缺失的服务器或端口。

`main_account_switch_token` 不是普通账号查询的必需步骤。首次读取可能生成并保存 token，返回内容也属于敏感凭证；只有用户明确需要该 token 且理解其用途时才考虑调用，不将它用于余额、用量或常规连接检查。
