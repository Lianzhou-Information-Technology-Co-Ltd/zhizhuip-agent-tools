# 获取已有代理并生成连接配置

## 账号与入口

1. 明确用户要使用的产品、账号或筛选条件，以及目标客户端和协议。产品不确定时读取 [产品选择](products.md)。
2. 用 `sub_account_list` 查询对应产品。按工具要求分页，存在多个候选账号时让用户选择，不随意取第一个。
3. 从结果读取代理入口 `target`、端口 `port`、账号 `username` 和密码 `password`。普通产品的协议字段通常是 `agree`，动态带宽产品为 `protocol`，按实际返回和工具说明解释。
4. 将已有代理信息转换为用户需要的配置格式。用户只要求生成配置时，到此完成；不得自动创建账号、购买产品或发送测试流量。

`ip` 可能表示出口 IP，不能直接代替代理入口 `target`。不要根据产品名称猜域名、端口或账号后缀。连接字段为空时，说明暂时缺少可用连接信息，读取 [问题排查](troubleshooting.md)；列表查询成功本身不证明代理可用。

当前 MCP 提供的是已有子账号连接信息，没有独立的“提取出口 IP”或“执行换 IP”工具。用户所说的“提取”若有歧义，区分其需要连接配置还是实际观察到的出口 IP。

## 动态住宅流量会话

对 `dynamic-no-expiry` 和 `dynamic-monthly` 的会话配置，优先读取 MCP 资源 `zhizhuip://docs/dynamic-proxy-session`。若客户端无法读取该资源，可以使用下列已明确的基础规则；超出这些规则时，请用户提供官方说明，避免猜测。

- 代理用户名可以附加 `cty`、`st`、`ct`、`ss`、`tm`、`spec` 参数，密码仍取账号实际密码。地区代码与名称从对应地区工具查询。`provider_list` 当前只读取永久流量主账号的资源池配置；期限流量指定 `spec` 前须在网站核实适用性，不能直接套用该查询结果，详见[地区与资源池查询](products.md#地区与资源池查询)。
- 指定州或城市前先确定国家。不要把州或城市的数字 ID 直接当作连接串中的名称。
- 需要保持会话时使用 `ss`，不同独立会话使用不同的值；不带 `ss` 的一次一换规则以该资源说明为依据。
- `tm` 带单位，例如 `20m`。相同会话请求保持同一 IP 的能力受资源可用性影响，IP 掉线时可能替换，不能承诺绝不变化。
- 更换 `ss` 是连接参数变化，不是调用创建子账号接口；不同会话也不能被描述为已经实测得到不同出口 IP。
- 不把上述会话规则直接套用到静态产品或动态带宽产品。

例如，已有账号为 `YOUR_PROXY_USERNAME`，需要美国、20 分钟会话时，用户名可组织为：

```text
YOUR_PROXY_USERNAME-cty-US-ss-session-a-tm-20m
```

随后结合查询到的协议、入口、端口和原密码生成配置。示例中的账号、会话值均为占位信息，不能作为真实凭证或已分配资源报告。

## 输出与验证

- 使用目标客户端要求的字段和格式；用户名、密码、空格及特殊字符按该客户端的转义规则处理，不把 shell 引号原样复制进其他客户端的字段。
- 优先用单独的用户名和密码字段或本机环境变量生成程序示例，避免把真实凭证写进可分享的源码。
- 用户要求实际测试时，使用其指定或认可的测试目标，控制请求范围，并提醒测试可能消耗代理流量。输出实际观察到的结果，不根据地区参数推断出口已经匹配。
- 无法发起代理请求时，交付配置和验证方法，明确本轮只完成配置生成。
