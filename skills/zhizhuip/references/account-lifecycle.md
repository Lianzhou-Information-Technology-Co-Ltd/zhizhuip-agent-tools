# 子账号新增、修改与删除

先通过 `sub_account_list` 确认产品、目标和当前状态，按用户选定的范围操作。所有写工具逐次确认；实际返回后复核。批量部分失败时保留成功结果，只处理明确失败的目标，不能整批盲目重试。

## 新增动态流量子账号

`sub_account_add` 仅用于永久、期限两种动态流量产品，不用于动态带宽或静态产品。

1. 用 `main_account_flow` 和必要的 `flow_package_list` 核实所选主账号已购流量。没有可用套餐时说明购买前提，不擅自先购买。
2. 从[产品选择](products.md)的地区流程取得国家、州、城市和必要的资源池。确认数量、地区、协议、切换间隔；`num` 为 1–500，`changeInterval` 单位分钟、范围 1–120，协议省略由 MCP 补为 `SOCKS5`。
3. 展示具体新建方案。新增本身不另扣购买费，实际代理使用消耗主账号流量；不能理解为免费获得流量。
4. 确认后调用，处理返回的新账号，再用列表复核。返回的账密仅用于用户要求的交付，不在普通报告展开。

后端有 10 秒重复请求拦截，它不是完整幂等机制。超时后先查列表和网站记录，不能等 10 秒就重复新建。用户要求“创建且设置上限”时，当前 MCP 需要新增后另调限流写工具，两步不是原子操作。限流失败时账号可能已创建且没有所需限制，必须报告并让用户决定后续处理。

## 备注、间隔和限流的配置副作用

当前后端的动态账号更新、限流设置及各产品的账密修改会共用上游配置更新逻辑。省略字段时可能同时发送 `method=socks5`、`udp=false`、`failover=false`、`diffTarget=0`；动态流量切换间隔缺省为 300 秒，静态及数据中心账密更新发送 0 秒。批量更新明确传入的 `changeInterval` 按分钟换算；现有备注、限流及账密工具无法传齐保留现有配置所需的全部字段。

因此，不能保证“只改备注”“只改密码”或“只改限流，其他不动”。先说明这些影响：

- 用户要求严格保留其他配置时，停止这条写路径，说明需要网站核对或后端提供可靠的窄更新接口。不要假装先查一次就能保留 MCP 无法传递的字段。
- 用户接受上述配置变化后，才按具体参数发起写工具确认。不要未经同意把“修改备注”扩展成改协议或停用功能。
- 执行后核对列表和限流查询能返回的字段。未返回的上游配置不能宣称已保留或已验证；没有执行真实代理测试时不保证已有连接不中断。

单个备注用 `sub_account_update`，明确传入本次备注；批量备注或间隔用 `sub_account_update_batch`，`ids` 为英文逗号分隔字符串。没有要改的字段时不发空更新；省略可选字段不代表后端无副作用。

## 流量上限

1. 单个查询用 `sub_account_limit_flow` 的 `account`；批量查询用 `sub_account_limit_flow_batch` 的 `accounts` 逗号字符串，默认第 1 页、每页 100，更多记录继续分页。
2. `sub_account_set_limit_flow` 传 `account/cycle/limit_flow`；批量 `sub_account_set_limit_flow_batch` 传同一 `cycle` 和 `accounts:[{account,limit_flow}]`，每个账号可有不同上限。
3. 单位为 GB，单条整数 0–100000000，批量每条整数 0–1000000；`cycle` 为 0 每天、1 每周、2 每月、3 每季度、4 每年、5 永久。一个子账号只能有一种周期，变更会替换原限制。
4. `limit_flow=0` 表示删除限制，绝不是断流或禁止使用。周期 5 按累计用量，不会周期清零；其他周期达到上限后断开、下一周期恢复。
5. 先说明上一节的配置副作用，再确认并执行。复查限制、周期和已用量，不只看 `code`。

单条无配置时查询返回 `[]`；批量查询返回平面记录数组，不是 `rows/total`，不能因为没有总数字段就断言没有更多记录。`use_flow` 是已保存统计值，不保证为调用瞬间的实时值。

批量返回需要检查 `success_count/fail_count` 及失败明细（以实际字段为准）。后端先处理本地限制记录，再尝试上游更新，批量失败分支可能删除该账号限制记录；失败不是“保持原配置”。单条更新有本地事务回滚，不能由此保证上游也回滚。不能仅重试整批，也不能声称完整回滚成功。重新读取失败对象的限制并说明当前已核实状态。

删除限制的解除停用逻辑存在参数覆盖问题。查询到限制已删除并不保证上游账号已恢复可用；报告已核实的配置结果，需实际连通验证时另按用户授权执行。

## 账密、端口和白名单

| 任务 | 工具与输入 | 前提及完成核对 |
| --- | --- | --- |
| 设置自定义账密。 | `sub_account_set_credentials`，`content:[{id,customUsername,customPassword}]`。 | 除动态带宽外按枚举选产品。用户名和密码均为 8–30 位字母或数字；会覆盖两项并影响现有连接。执行后列表复核，报告时掩码。 |
| 仅批量改密码。 | `sub_account_set_password_batch`，`content:[{id,customPassword}]`。 | 仅静态住宅 IPv4、数据中心，且已使用自定义账密。系统默认账密不适用；不要自动改用上一工具并一起改用户名。 |
| 开关 IP 端口连接。 | `sub_account_toggle_port`，`ids` 逗号字符串、`use_ip_port` 为 0 或 1。 | 仅静态住宅 IPv4，单次最多 200 个；关闭会影响连接，不等于删号或退款。执行后列表复核可见状态。 |
| 读取白名单。 | `sub_account_whitelist`，动态流量产品及 `id`。 | 只读查询，没有白名单修改工具。读取为空也不授权清空或改写。 |

两类账密工具同样受上一节的默认配置影响。“仅改密码”是提供的业务字段范围，不是后端窄更新保证；静态/数据中心的密码更新也可能改成 SOCKS5 等默认配置。用户要求保持协议等其他字段时不能直接执行。动态带宽不在这些账密工具范围内，不将上述结论当成对其独立后端分支的验证。

所有批量操作都核对对象数量和每项结果；不把 HTTP 成功或整体 `code=1` 解释为每个账号都成功。

## 删除动态流量子账号

1. 列出将删除的具体产品和 ID，说明连接将不可用且不可恢复。删除不是退单或退还已消耗流量。
2. 单删 `sub_account_delete` 传字符串 `id`；批删 `sub_account_delete_batch` 传英文逗号分隔的 `ids`。不能删除静态或动态带宽账号。
3. 取得确认后执行。若返回 `code=1` 但 `msg` 为“删除失败!未查询到子账号”，报告“接口提示未找到，不能确认本次删除成功”，不把它当作新发生的成功删除。
4. 再查目标列表。目标已不存在可以报告当前查询未找到，但不能据此证明是谁、何时删除。分页未覆盖完、查询失败或上游异常时保留结果未知，不反复发删号请求。
