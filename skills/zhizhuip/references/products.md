# 产品选择与能力范围

先确认用户要使用已有代理、购买新产品，还是管理已有账号。用户已指定产品时沿用该产品；只说“住宅代理”时，先确认是否需要固定出口、目标地区、使用期限和计费偏好，不自行替换产品。

## 产品枚举

| `product` | 产品 | 选择时需要确认的区别 |
| --- | --- | --- |
| `dynamic-no-expiry` | 动态住宅流量（永久） | 按流量使用，适合用户明确选择永久流量的需求；不要把“永久”解释为固定出口或永久可用的连接。 |
| `dynamic-monthly` | 动态住宅流量（期限） | 当前仅支持 30 天，`bill_timelen` 省略时默认 1；不支持 90 或 180 天。 |
| `dynamic-bandwidth` | 动态住宅不限流量（带宽） | 按带宽与时长选购，使用 Mbps 表达带宽，不能与按 GB 购买的流量产品混算。 |
| `static-standard` | 静态住宅（非原生） | 用户需要静态住宅且选择非原生类型时使用。 |
| `static-native` | 静态住宅（原生） | 用户明确需要原生静态住宅时使用。 |
| `static-isp-native` | 静态住宅（运营商原生） | 用户明确选择运营商原生类型时使用，不与普通原生产品合并。 |
| `static-ipv6` | 静态住宅（IPv6） | 先确认客户端和目标业务支持 IPv6，不把 IPv4 的使用条件直接套用。 |
| `datacenter` | 数据中心 | 用户接受数据中心出口时使用，不自动替代住宅产品。 |

不要承诺某产品一定能访问特定网站、通过平台风控或长期保持同一出口。价格、库存、地区和协议以当前工具结果及产品说明为准，不凭产品名称推断。

## 当前能力范围

所有产品均可通过 `sub_account_list` 查询已有子账号。其他操作按产品区分：

| 产品范围 | 已有 MCP 能力 |
| --- | --- |
| 两种动态住宅流量产品 | 购买流量、查询已购套餐和用量、查询地区及供应商、新建及删除子账号、修改备注和切换间隔、设置流量上限、设置自定义账密、查询白名单。 |
| 动态不限流量（带宽） | 查询子账号、新购、续费、升级带宽、申请退单。 |
| 三种静态住宅 IPv4 产品 | 查询子账号与 IP 段库存、购买及续费、设置账密、开关端口连接、查询及升级带宽、申请退单、预约 IP。 |
| 静态住宅 IPv6 | 查询子账号、购买、续费、设置自定义账密。 |
| 数据中心 | 查询子账号、购买、续费、设置账密、预约 IP。 |

这张表用于选择流程，实际调用前仍要检查当前会话暴露的工具及其 `product` 枚举。专用工具可能不接收 `product`，不要额外补入。不要注入 schema 没有的 `type`、`status`、`native`、`version` 或 `product_type_id` 来绕过工具范围；`coupon_list` 的 `type/status` 是正式筛选参数，应正常传递。

`user_price`、`official_price` 和 `coupon_list` 可辅助选购，但当前 MCP 的价格查询不包含动态不限流量带宽报价，也没有该产品的库存查询工具。需要该产品的准确费用时，引导用户在网站核实，再按购买流程处理；不能沿用其他产品价格。

## 地区与资源池查询

1. 用同一产品的 `country_list` 获取国家 `id` 和编码。
2. 动态流量先用 `state_list`，带 `country_id` 及工具支持的国家编码，再用 `city_list` 带国家和州省标识。时长产品直接按国家查城市，不套用动态州省流程。
3. 新增账号的 `state/city`、连接串中的州/城市参数使用返回的名称，不能用数字 ID 替代。购买的 `country` 通常用二字码；预约例外，使用国家名称。
4. 静态住宅 IPv4 用 `ip_range_status` 按国家、城市和 IP 段筛库存，注意分页参数是 `pageSize`。返回的段才可用于 `ip_str/specifyIps`；指定分段时各项 `count` 之和等于购买数量。查询结果只代表当时库存，不保证下单仍有货。

`provider_list` 当前返回资源池编号字符串数组，例如 `["4","284"]`，不是 `{id: ...}` 对象数组。需要 `spec` 时校验选中值是整数编号后转为整数，一次只传一个；连接串按资源说明使用。当前后端此查询固定读取永久流量主账号，忽略期限标记；因此它的结果不能证明期限产品资源池可用。期限产品要求指定资源池时先在网站核实，无法核实时说明缺口，不试填猜测编号。

当前没有直接执行换 IP 的 MCP 工具。修改切换间隔不等于立即换 IP，读取切换 token 也不等于已执行切换。遇到未暴露的操作，说明能力缺口，不自行改为直接 HTTP 请求。
