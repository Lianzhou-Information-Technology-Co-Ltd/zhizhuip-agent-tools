# 动态代理 Session 用法

本文用于生成动态住宅流量代理的连接配置。先通过 `sub_account_list` 取得现有子账号的用户名、密码、服务器、端口和协议，不根据示例猜测入口，也不默认把 Session 语法用于动态不限流量或静态产品。

## 连接参数

在支持此语法的动态流量入口中，可在返回的用户名后追加连接参数；密码保持原值。以下内容都是占位示例，不能直接当成真实账号或入口使用。

```text
<用户名>-cty-<国家>-st-<州省>-ct-<城市>-ss-<会话标识>-tm-<时长>-spec-<资源池编号>
```

| 字段 | 用途 |
| --- | --- |
| 原用户名 | 必须在开头，沿用查询返回的用户名，不自行拼接产品后缀。 |
| `cty` | 国家编码，从该产品的国家列表取得。 |
| `st` | 州或省，需要与国家匹配，使用州省列表返回的名称。 |
| `ct` | 城市，需要与国家及州省匹配，使用城市列表返回的名称。 |
| `ss` | 会话标识，需要区分的会话使用不同值；复用同一会话时保持该值和地区条件一致。 |
| `tm` | 请求的会话时长，带单位 `s`、`m` 或 `h`，例如 `20m`。 |
| `spec` | 可选资源池编号；只使用已确认适用于目标账号的资源池，不固定写死编号。 |

`provider_list` 返回编号字符串数组，当前后端读取的是永久流量主账号的资源池配置，选择期限产品也不改变这个查询来源。不要把该结果当作期限账号资源池权限的保证。

未指定的条件通常沿用账号或入口规则；不要把省略 `ss`、地区或 `tm` 解释为必然每次换 IP、全球随机或某个固定时长。

## 生成配置

用户需要一个美国地区、请求保持 20 分钟的会话时，可生成：

```text
用户名：<原用户名>-cty-US-ss-sessionA-tm-20m
密码：<查询返回的密码>
服务器：<查询返回的 target>
端口：<查询返回的 port>
协议：<查询返回的协议>
```

用户需要两个独立会话时，使用不同的标识：

```text
<原用户名>-cty-US-ss-sessionA-tm-20m
<原用户名>-cty-US-ss-sessionB-tm-20m
```

这里创建的是连接配置中的会话标识，没有调用 `sub_account_add`，不会因为改变 `ss` 就创建一个新的平台子账号。不同会话标识也不保证得到不同的出口 IP；是否可分配及实际出口由代理服务和可用资源决定。

地区包含空格时，先保留接口返回的完整名称，再根据目标客户端正确引用整个用户名。例如用户名可以包含 `-st-New York-`；命令行引号用于保护整个参数，不是应写入代理用户名的字符。不要在未确定客户端格式前输出一条跨平台通用命令。

## 结果与限制

- Session 配置表达期望的地区与会话时长，不保证出口 IP 在整个时段内不变。资源掉线、入口策略或重新分配都可能影响实际出口。
- 切换会话标识不等于已经调用换 IP 接口。当前 MCP 没有直接执行换 IP 的工具，`main_account_switch_token` 只返回 token，不能用于证明已完成切换。
- 生成配置不证明代理已连通。没有实际连通性验证时，只报告“配置已生成”，不要声称目标网站已访问成功或出口已符合预期。
- 连接字段为空时停止生成可执行配置，先说明缺失的服务器、端口或协议。不要回退到文档中的固定入口。
- 不保留固定资源池编号、吞吐量、成功率或带宽性能承诺；使用当前产品信息和实际验证结果。
